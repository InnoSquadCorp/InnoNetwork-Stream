## Verification matrix and boundaries

| Path | Evidence | Result / boundary |
| --- | --- | --- |
| Normal PR, source/tests/consumers/dependencies | Changed-path and original workflow inventory tests | All existing distinct gates retained |

| Failure, cancellation, missing/skipped results | Aggregate and proof negative controls | Cannot turn incomplete validation into success |

| Retry/restoration | Latest attempt/provenance tests where automation exists | Unknown or racing evidence blocks; no synthetic CI success |
| Security/resource limits | Pinned actionlint with archive digest, malformed archive/diagnostic tests; workflow permissions/timeouts | Existing permissions preserved or reduced |
| Public/runtime contracts and consumers | Fresh local checks below; original workflow command/matrix fixtures | No production Swift/dependency changes |

Fresh evidence is from this isolated worktree. Reused design: the previously
