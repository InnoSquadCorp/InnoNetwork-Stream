# InnoNetwork-Stream 6.1.1 Release Candidate

Status: Release candidate (unpublished)
Release date: Not scheduled

The maintainer selected `6.1.1` to align this release number with Network.
This is the first planned stable Stream tag, not a patch to a published Stream
1.0.0. No merge, tag, GitHub Release, or production rollout is implied.

## Candidate scope

- Core dependency: exact `6.1.1`, published tag revision
  `44e4ca28c50c03f817231a077c0f3bdfdbc859c8`. Core source remains untouched.
- Supported public surface and breaking migrations: [API Stability](../../API_STABILITY.md).
- Bounded HLS parsing, steering, AES keys, offline operations, cancellation,
  coherent rolling DVR checkpoints and timeline expiry.
- Observable key-preload cancellation and injected persistence-failure controls.
- Local Apple-tool evidence on SDK-generated offline and DVR media, reviewed
  separately from ordinary fixture and AVPlayer runtime CI.
